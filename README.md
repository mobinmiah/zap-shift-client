# ⚡ ZapShift — Parcel Delivery & Transportation Platform

ZapShift is a full-stack MERN web application that connects users who want to send parcels with registered delivery bikers, all managed through a powerful admin panel.  
The platform provides a fast, secure, and reliable solution for modern parcel transportation.

---

## 🌐 Live Demo
🔗 [https://zap-shift-by-mobin.netlify.app]

---

## 🧾 Project Overview
ZapShift allows users to create accounts and send parcel delivery requests, while bikers can register to accept and complete deliveries.  
Admins have full control over the system including user management, delivery approvals, and platform operations.  
The application is built with scalability, security, and performance in mind.

## 🧰 Technologies Used

**Frontend:** React, Tailwind CSS  
**Backend:** Node.js, Express.js  
**Database:** MongoDB  
**Authentication:** Firebase  
**Security:** JWT  
**Tools:** Git, GitHub, VS Code  

---

## ✨ Core Features
- User registration & parcel creation  
- Biker registration & delivery management  
- Role-based authentication (User, Biker, Admin)  
- Admin dashboard with full platform control  
- Secure payment & delivery tracking  
- Real-time delivery status updates  
- Responsive & modern UI  
- Secure API handling
